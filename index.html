What's inside

Every tool has a guide card inside Maya, so you learn it where you use it.

Keys and curves

Copy and paste poses and animation ranges, Nudge Keys, curve shaping and smoothing, tangents, Euler Filter and static channel cleanup.

Animation layers

Create layers, work with their channels, then merge and bake.

Spaces and helper nodes

World Nodes, Rotation Nodes, Aim Offset, Temp Pivot and Space Switcher.

Copy Xform Relationship

Store how objects sit relative to each other, apply it again, keep it as a live link or bake it.

Character work

Mirror poses and animation, select opposite controls, IK/FK tools.

Some rigs need a one-time profile setup.

Organization and visual control

Selection Sets, rig profiles, Arc Tracker and Motion Trails, hotkeys and configurable hints.

Secondary motion

Overlap and dynamics tools for delayed, flowing motion on control chains.

Ragdoll tools are in development.
